# RC Internship Certificate Generator

Готовая статическая версия для GitHub Pages.

## Структура

- `index.html` — главная страница
- `assets/fonts/` — шрифты
- `assets/images/` — изображения и favicon

## Публикация через GitHub Pages

1. Загрузите **всё содержимое этой папки** в корень репозитория.
2. Убедитесь, что `index.html` лежит в корне рядом с папкой `assets`.
3. GitHub → Settings → Pages.
4. Source: `Deploy from a branch`.
5. Branch: `main`, Folder: `/(root)`.
6. Save.

Не загружайте ZIP как один файл в репозиторий — сначала распакуйте его.
